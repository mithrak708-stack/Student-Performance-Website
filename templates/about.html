About This Project

The Student Performance Prediction System is a Machine Learning web application that predicts a student's academic performance based on:

  • 📚 Hours Studied
  • 🎯 Attendance Percentage
  • 📈 Previous Score
  • 😴 Sleep Hours
  • 📝 Practice Papers
  • 🤖 Machine Learning Prediction
